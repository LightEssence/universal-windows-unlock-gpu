# Universal Multi-GPU Windows Unlock Engine (Ampere & Ada Lovelace)

[English](README_EN.md) | [Русский](README.md)

> **100% Volatile In-RAM Unlock — Zero Physical SPI Flash Writes.**  
> Безопасная энергозависимая разблокировка полной вычислительной производительности GPU (FP32 / FP16 / BF16 Tensor Cores) для Windows 10/11 через автономный UEFI-загрузчик.  
> *Создано на основе и в развитие кодовой базы проекта [JustAResearcher/gpu-unlock-ada](https://github.com/JustAResearcher/gpu-unlock-ada).*

## 🎯 Ключевые возможности архитектуры

1. **Полная независимость от материнской платы:**
   * Автоматический динамический поиск Windows Boot Manager (`bootmgfw.efi`) по всем FAT/ESP разделам без захардкоженных GUID или путей.
   * Динамическое освобождение дисплея по стандарту UEFI (`DisconnectController`) без специфичных ACPI-путей.
   * Корректная синхронизация PCI Command Register (IO + Memory Space decode) и шины Bus Mastering перед передачей управления GSP/Falcon движку.

2. **Поддержка нескольких видеокарт (Multi-GPU / Dual Unlock):**
   * Сканирование всех PCI-рутов, мостов и сокетов (актуально для многопроцессорных систем Dual Xeon / EPYC / Threadripper).
   * Поддержка одновременной работы карт архитектур **Ampere (RTX 30xx)** и **Ada Lovelace (RTX 40xx)**.
   * Интеллектуальное разделение ролей: адаптер вывода изображения (Display Adapter с активным GOP) и чистые вычислительные ускорители (Headless Compute).

3. **Строгая адресация VBIOS по аппаратному Hardware ID:**
   * Полный отказ от неоднозначных имен вида `vbios.rom`.
   * Файлы именуются строго по PCI Subsystem ID:
     `\EFI\VBIOS\<VENDOR>_<DEVICE>_<SUBVENDOR>_<SUBDEVICE>.rom`
     *(например: `\EFI\VBIOS\10de_2782_1458_40e8.rom`)*.
   * Если в системе установлено несколько одинаковых карт, образ VBIOS загружается в RAM один раз и переиспользуется для всех совпадающих адаптеров.

4. **Прямое выделение страниц памяти (Zero-Allocation-Failure):**
   * Для тяжелых прошивок (таких как `gsp_ga10x.bin` размером 84.3 МБ) загрузчик использует прямое постраничное выделение физической памяти (`gBS->AllocatePages`), гарантируя успешный старт даже на UEFI-прошивках с фрагментированным системным пулом.

## 🚀 Быстрый старт

### 1. Подготовка флешки
Отформатируйте любую USB-флешку в файловую систему **FAT32**.

### 2. Снятие дампов VBIOS в Windows (1 клик)
1. Подключите флешку к ПК.
2. Запустите `dump_vbios.bat` от имени Администратора.
3. Скрипт автоматически определит все установленные видеокарты NVIDIA и сохранит дампы в папку `EFI\VBIOS\` с правильными именами аппаратных идентификаторов (например, `10de_2782_1458_40e8.rom`).

### 3. Развертывание загрузчика
Выполните скрипт копирования:
```bat
copy_to_usb.bat
```
*(или через PowerShell: `powershell -ExecutionPolicy Bypass -File .\copy_to_usb.ps1 -DriveLetter <Буква_Флешки>`)*

Скрипт перенесет:
* `\EFI\BOOT\BOOTX64.EFI` — автономный загрузчик.
* `\EFI\ASSETS\` — полный набор микрокода для Ampere и Ada Lovelace.
* `\EFI\VBIOS\` — дампы VBIOS ваших видеокарт.

### 4. Загрузка через UEFI
1. Перезагрузите ПК и вызовите UEFI Boot Menu (`F11`, `F12` или `F8`).
2. Выберите пункт загрузки с USB-накопителя (`UEFI: <Ваша Флешка>`).
3. Загрузчик просканирует шину PCI, отобразит найденные видеокарты и предложит выбор:
   * **[U] Unlock All Ready GPUs & Boot Windows** — применить разблокировку в оперативной памяти и загрузить Windows.
   * **[S] Boot Stock Windows** — загрузить Windows в штатном режиме без изменений.
   *(Через 10 секунд автоматически выбирается режим `[U]`)*.

## 🛠 Компиляция из исходников

Для сборки проекта используется входящий в окружение тулчейн `w64devkit` (GCC 16.2.0):

```powershell
python build.py
```

Скрипт компилирует все модули C с оптимизацией `-O2`, компонует PE32+ исполняемый файл и автоматически обнуляет таблицу импорта (PE Import Directory), исключая ошибки зависимости от внешних динамических библиотек в среде UEFI ImageLoader.

Разработка данного загрузчика опирается на фундаментальные исследования и открытые исходные коды:

1. **[JustAResearcher/gpu-unlock-ada](https://github.com/JustAResearcher/gpu-unlock-ada)** — **Базовый первоисточник (Base Upstream Repository)**  
   Искренняя благодарность автору за фундаментальную работу по адаптации алгоритма разблокировки для архитектуры Ada Lovelace, структуру инжекции транзакций V67 Falcon и первую реализацию под UEFI. Настоящий репозиторий развивает и обобщает эти наработки в универсальный мульти-GPU загрузчик (поддержка Multi-GPU, одновременная работа Ampere + Ada, независимость от специфики плат и ACPI, синхронизация PCI Command/BME).

2. **[NVIDIA Open GPU Kernel Modules](https://github.com/NVIDIA/open-gpu-kernel-modules)**  
   Официальные открытые модули ядра NVIDIA, документация протоколов инициализации GSP (GPU System Processor) и Falcon микроконтроллеров.

3. **Проект `gpu-unlock` и исследовательское сообщество V67 Falcon**  
   Исследования формата разметки прошивок Falcon, алгоритмов валидации SEC2, внедрения промежуточного загрузчика V67 и энергозависимого переключения аппаратных скоростных селекторов в MMIO.

4. **[Tianocore EDK II](https://github.com/tianocore/edk2)**  
   Инфраструктура и спецификации Unified Extensible Firmware Interface (UEFI), стандарты взаимодействия с протоколами `EFI_PCI_IO_PROTOCOL` и `EFI_GRAPHICS_OUTPUT_PROTOCOL`.
