# Universal Multi-GPU Windows Unlock Engine (Ampere & Ada Lovelace)

> **Безопасная энергозависимая разблокировка вычислительной производительности GPU для Windows 10/11.**  
> **100% Volatile In-RAM Unlock — Zero Physical SPI Flash Writes.**

---

## 🎯 Ключевые возможности

1. **Полная независимость от материнской платы:**
   * Работает на любых платформах: **Intel X99, Z490, Z790**, **AMD B450, X570, X670**, односокетных и двухсокетных рабочих станциях (Dual Xeon / EPYC / Threadripper).
   * Автоматический динамический поиск `bootmgfw.efi` (Windows Boot Manager) на всех разделах системы без захардкоженных GUID дисков.
   * Динамическое освобождение дисплея по стандарту UEFI (`DisconnectController`) без специфичных ACPI-путей.

2. **Поддержка нескольких видеокарт (Multi-GPU / Dual Unlock):**
   * Автоматическое сканирование шины PCIe по всем сегментам, шинам и сокетам.
   * Поддержка тандемов: **RTX 4070 Ti (AD104) + RTX 3060 (GA106)**, ферм из одинаковых карт или разнородных ускорителей.
   * Разделение ролей: если одна карта выводит картинку (Display Adapter с активным GOP), а вторая работает как чистый ускоритель (Headless Compute), экран не гаснет, а инференс-карта получает 100% свободной VRAM без оверхеда рабочего стола Windows!

3. **Строгая адресация VBIOS по Hardware ID (Никаких `vbios.rom`):**
   * Файлы именуются строго по аппаратному идентификатору PCI:  
     `\EFI\VBIOS\<VENDOR>_<DEVICE>_<SUBVENDOR>_<SUBDEVICE>.rom`
   * **Примеры:**
     * Gigabyte RTX 4070 Ti Gaming: `10de_2782_1458_40e8.rom`
     * Gigabyte RTX 3060 Eagle OC: `10de_2504_1458_40e2.rom`
   * **Идентичные карты:** Если в системе установлены две одинаковые видеокарты с одинаковым Subsystem ID, загрузчик автоматически применяет один и тот же файл VBIOS из RAM для обеих карт без дублирования I/O.

4. **Абсолютная безопасность (Zero SPI Flash Writes):**
   * Загрузчик **НЕ прошивает** физическую микросхему SPI Flash на видеокарте (риск окирпичивания исключён на 100%).
   * Все модификации выполняются исключительно в оперативной памяти хоста (Host RAM) и внутренних теневых регистрах контроллера Falcon (BAR0 MMIO: селекторы SS0/SS1).
   * После перезагрузки без флешки все видеокарты остаются в **100% заводском стоковом состоянии**.

## 🚀 Быстрый старт

### Шаг 1. Снятие дампов VBIOS в Windows (1 клик)
1. Вставьте подготовленную FAT32 флешку в ПК.
2. Запустите файл `dump_vbios.bat` от имени Администратора.
3. Скрипт сам определит установленные карты и сохранит дампы в папку:
   ```text
   USB:\EFI\VBIOS\10de_2782_1458_40e8.rom
   USB:\EFI\VBIOS\10de_2504_1458_40e2.rom
   ```

### Шаг 2. Загрузка через UEFI
1. Перезагрузите ПК и откройте меню выбора загрузки (клавиша `F12`, `F11` или `F8`).
2. Выберите загрузку с USB-накопителя (`UEFI: USB Drive`).
3. Экран загрузчика отобразит сводку по всем найденным картам:
   ```text
   ======================================================================
        UNIVERSAL MULTI-GPU WINDOWS UNLOCK ENGINE (AMP/ADA)
       Safety Guaranteed: 100% Volatile In-RAM Unlock (Zero SPI Flash)
   ======================================================================

   Detected Supported GPUs: 2
   ----------------------------------------------------------------------
   [GPU 0] RTX 4070/4070Ti (AD104) on Bus 3:0.0
           ID: 10de_2782_1458_40e8 | BAR0: 0xc6000000 [Display Adapter (GOP)]
           VBIOS: \EFI\VBIOS\10de_2782_1458_40e8.rom (626 KB) -> [LOADED IN RAM]
   [GPU 1] RTX 3060 (GA106) on Bus 130:0.0
           ID: 10de_2504_1458_40e2 | BAR0: 0xd2000000 [Headless Accelerator]
           VBIOS: \EFI\VBIOS\10de_2504_1458_40e2.rom (1024 KB) -> [LOADED IN RAM]
   ----------------------------------------------------------------------

   Boot Options:
     [U] Unlock All Ready GPUs & Boot Windows (Automatic in 10s)
     [S] Boot Stock Windows (Bypass Unlock)
   ```
4. Нажмите `U` (или дождитесь 10-секундного таймаута) — загрузчик применит разблокировку в RAM и передаст управление Windows.

## 🛠 Архитектура исходного кода

```
universal-windows-unlock-gpu/
├── include/
│   ├── uefi_base.h         # Базовые типы EDK2, системные протоколы и логирование
│   ├── gpu_types.h         # Определение типов архитектур (Ampere / Ada) и дескрипторов карт
│   ├── pci_scan.h          # Интерфейс сканера шины PCIe (Multi-GPU топология)
│   ├── vbios_loader.h      # Загрузчик ROM с FAT32 по строгому аппаратному ID
│   ├── vbios_parser.h      # Парсинг PCIR / BIT / FWSEC на лету без хардкода
│   ├── display_release.h   # Универсальное освобождение GOP через DisconnectController
│   ├── unlock_engine.h     # In-RAM Falcon/GSP транзакция (SS0/SS1, FLR)
│   └── sha256.h            # Верификация контрольных сумм
├── src/
│   ├── app.c               # Точка входа UefiMain и цветной интерактивный интерфейс
│   ├── pci_scan.c          # Сканирование всех PCI-рутов, фильтрация по 30/40 серии
│   ├── vbios_loader.c      # Чтение \EFI\VBIOS\<HW_ID>.rom, поддержка общих дампов
│   ├── vbios_parser.c      # Извлечение смещений FWSEC из VBIOS в оперативной памяти
│   ├── display_release.c   # Материнко-независимое отключение дисплейного контроллера
│   ├── unlock_engine.c     # Установка селекторов скорости 0x88888888 в RAM + FLR
│   └── sha256.c            # Криптографический модуль
├── tools/
│   └── package_usb.py      # Автоматическое развертывание дистрибутива на флешку
├── build.py                # Компиляция через w64devkit GCC/LD в BOOTX64.EFI
├── dump_vbios.ps1          # Скрипт автоопределения карт и дампа по ID
└── dump_vbios.bat          # 1-click запуск с правами Администратора
```

## 🔧 Сборка проекта из исходников

Для сборки используется входящий в состав репозитория тулчейн `w64devkit` (GCC 16.2.0):

```powershell
python build.py
```

Результат сборки помещается в `dist/EFI/BOOT/BOOTX64.EFI` (размер ~26 КБ, зависимости PE Imports очищены).

Для создания готовой структуры на флешке:
```powershell
python tools/package_usb.py "E:\"  # Где E: - буква вашей флешки
```
